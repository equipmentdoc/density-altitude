# Density Altitude Calculator PWA

## Install on Pixel using GitHub Pages
1. Create a new **public** GitHub repository (for example `density-altitude`).
2. Upload the files in this folder to the repository root (not inside another folder).
3. In GitHub open **Settings → Pages** and set **Deploy from a branch**, `main`, `/ (root)`. Save.
4. Wait for the published `https://YOUR-USERNAME.github.io/density-altitude/` URL.
5. Open that URL in Chrome on the Pixel. Tap **⋮ → Add to Home screen → Install**.

The app loads offline after the first successful visit. Live METAR lookup requires internet access and may depend on AviationWeather.gov CORS/access availability.

**Caution:** This is supplemental situational-awareness software, not certified aircraft performance software. Verify all values against official sources and your aircraft POH/AFM.
